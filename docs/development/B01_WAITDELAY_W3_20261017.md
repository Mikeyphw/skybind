# Skybind B01-W3 — Full uncached per-package Go regression

## Why this exists

On native Termux Go 1.27.1, Skybind's complete Go regression intermittently
reports `exec: WaitDelay expired before I/O complete` even at `-p 1`.
The failed package changes across runs (`lifecycle`, `policy`, `opevents`,
`paths`, and now `supervisor`). All four original suspects passed uncached
when run individually. The true runtime / FD cause is still not established.

**Do not suppress or reinterpret these Go errors.** W3 instead isolates each
package into a separate Go process while still executing every discoverable
package in the module. The tool refuses successful classification if any
package fails, times out, produces invalid/incomplete test JSON, has unexpected
terminal events, or if the Go source changes during the run. It disables
ambient `GOFLAGS` and `GOWORK` to avoid unobserved reduced coverage, and uses
`-count=1` throughout. Logs and an incrementally persisted JSON receipt go to
private `build/evidence/go-regression-isolated/<timestamp>/` directories.
A source digest captures the checked Go tree, including current uncommitted
B01 changes. Do not infer Android or broker qualification from this pass.

## Scope of overlay

- `.devtool.toml`: `r1-full-regression` uses full per-package Devtool job.
- `r1-go-runner-diagnostic`: native GoRunner's original monolithic test path
  remains accessible for triage, but is not reinterpreted as successful.
- `tests/test_r1_go_runner_policy.py`: source-policy assertions updated.
- `tests/test_go_all_packages_w3.py`: negative/false-pass controls.
- `scripts/dev/diagnostics/go_all_packages.py`: full per-package Go suite.
- `docs/development/B01_WAITDELAY_W3_20261017.md`: evidence and limits.

## Apply in Termux

```sh
unzip -q ~/storage/downloads/SKYBIND_B01_TERMUX_GO_ISOLATED_W3_20261017.zip -d ~/skybind-b01-w3
python3 ~/skybind-b01-w3/install.py --repository ~/Code/skybind --check
python3 ~/skybind-b01-w3/install.py --repository ~/Code/skybind --apply
cd ~/Code/skybind
python3 -m unittest tests.test_r1_go_runner_policy -v
devtool -r "$PWD" invoke r1-full-regression --target skybind_release
```

The new Go stage should call
`python3 scripts/dev/diagnostics/go_all_packages.py --timeout-seconds 240`.
The older direct GoRunner remains available via:

```sh
devtool -r "$PWD" invoke r1-go-runner-diagnostic --target skybind_release
```

**No Android APK build occurs locally.** The existing Android GitHub Actions
workflow is unchanged. No application Go code or user/device data is modified.

## Qualification

The script's `qualified=true` means *only* that all discovered Go packages
passed uncached with complete JSON and stable source identity in this run.
The full R1 workflow also requires BKX, chrootctl and broker-policy jobs.
It does NOT mean release qualification, real cross-UID IPC or Android device
acceptance. The initial Devtool GoRunner WaitDelay remains an open Devtool/Go
runtime diagnostic. Historical failures are retained as evidence.
