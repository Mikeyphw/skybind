# Skybind personal G03–G08 tracking

G03–G08 now report local first-party evidence (`PERSONAL_EVIDENCE_PASS`),
explicit personal owner acceptance (`PERSONAL_OWNER_ACCEPTED`), or
`PENDING_PERSONAL_CHECK`. They do **not** require externally pinned signing
keys, independent run-store custody or a four-manager physical-device matrix.

The original ledgers remain traceable historical requirements, not blockers
for single-device personal use. Owner acceptance is a scope declaration,
not proof that untested features work. Runtime ownership, symlink, namespace,
secrets, ZIP and signing safeguards remain in the implementation.
